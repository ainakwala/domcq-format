# Fixtures

`manifest.json` is the contract: each entry names a file and the error codes (and warning codes) the validator must report for it, as a sorted list of unique codes. An empty `errors` list means the file is valid.

- `valid/` — files that import cleanly: the smallest possible file, one using every optional field including `rationales` and a select-two answer, the same inside a ```` ```json ```` fence (`.md`), files for the two fictional modules, and an exported file with `exported_at` and `id`s. Files named `<module>-<ai>-<n>.json` are prompt-test outputs: what that AI returned, unedited, for the module's prompt from domcq.com (`generic-chatgpt-1.json` and `generic-gemini-1.json` are the base prompt's own test, 2026-10-15, both valid first time). When the AI's reply carried its own ```` ```json ```` fence, the reply is kept as it came, fence included, as `<module>-<ai>-<n>.md`. `pmp-claude-1.md` to `pmp-claude-4.md` are the PMP prompt's Claude runs (2026-10-15; 1–3 with the page defaults, 4 with per-option rationales on) and `pmp-chatgpt-1.json` is its ChatGPT run (2026-10-15, page defaults); all five valid first time. `cfa-l1-claude-1.md` to `cfa-l1-claude-4.md` and `cfa-l1-chatgpt-1.json` are the same for the CFA Program Level I prompt (2026-10-15; the ChatGPT reply was pasted back with Windows line endings and is kept that way); all five valid first time. `mbe-claude-1.md` to `mbe-claude-4.md` and `mbe-chatgpt-1.json` are the same for the Multistate Bar Examination (MBE) prompt (2026-10-15; 1–3 with the page defaults, 4 with per-option rationales on; the ChatGPT reply kept with its Windows line endings); all five valid first time. `aws-saa-claude-1.md` to `aws-saa-claude-4.md` and `aws-saa-chatgpt-1.json` are the same for the AWS Certified Solutions Architect - Associate prompt (2026-10-15; 1–3 with the page defaults, 4 with per-option rationales on; the ChatGPT reply kept with its Windows line endings); all five valid first time. `frm-p1-claude-1.md` to `frm-p1-claude-4.md` and `frm-p1-chatgpt-1.json` are the same for the FRM Exam Part I prompt (2026-10-15; 1–3 with the page defaults, 4 with per-option rationales on; the ChatGPT reply kept with its Windows line endings); all five valid first time. `comptia-secplus-claude-1.md` to `comptia-secplus-claude-4.md` and `comptia-secplus-chatgpt-1.json` are the same for the CompTIA Security+ prompt (2026-10-15 and 2026-10-16; 1–3 with the page defaults, 4 with per-option rationales on; the ChatGPT reply kept with its Windows line endings); all five valid first time.
- `invalid/` — one file per error code in SPEC.md §7, plus files that carry several errors at once to show that everything is reported in one pass. Non-JSON inputs are `.txt` or `.md`.
- `warnings/` — valid files that produce warnings.
- `modules/` — the fictional "Example Exam" (4 options, single answer, taxonomy, banned text) and "Example Cloud Associate" (4–5 options, multi-select) module configs. Real modules are added here, without the app-only fields, as their prompt-test outputs arrive: `pmp.json` is DoMcq's PMP module (PMI's July 2026 Examination Content Outline). `cfa-l1.json` is DoMcq's CFA Program Level I module (CFA Institute's 2027 Level I curriculum). `mbe.json` is DoMcq's Multistate Bar Examination module (NCBE's MBE Subject Matter Outline). `aws-saa.json` is DoMcq's AWS Certified Solutions Architect - Associate module (AWS's SAA-C03 Exam Guide). `frm-p1.json` is DoMcq's FRM Exam Part I module (GARP's 2026 FRM Study Guide). `comptia-secplus.json` is DoMcq's CompTIA Security+ module (CompTIA's Security+ SY0-701 V7 exam objectives).

Other implementations of `domcq/1` are welcome to run these; `test/fixtures.test.ts` shows how the manifest is consumed. Module threads in DoMcq add their prompt-test outputs here as further `valid/` fixtures.
